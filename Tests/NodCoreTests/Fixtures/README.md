# Motion fixtures

One file = one take = one label. Format: JSONL, one sample per line, keys sorted:

```json
{"label":"nod","pitch":0.31,"rotX":1.2,"rotY":0,"rotZ":0,"roll":0.01,"t":1000.016,"yaw":-0.2}
```

- `t`: seconds on the device clock (boot-relative), not wall time. Samples are bursty (~60 Hz moving, ~5 Hz still).
- `pitch`, `yaw`, `roll`: attitude in radians. `rotX/Y/Z`: rotation rate in rad/s.
- Labels: `nod`, `shake`, `tiltLeft`, `tiltRight` (gestures); `still`, `musicNod`, `lookAside`, `talking` (noise).
- Loader: `FixtureFile.decode`; replay with `FakeMotionSource(take:)`. Same code path for recorded and synthetic takes.
- `synthetic/` is generated by `scripts/gen-fixtures.sh` (seed 1 of each kind). It is synthetic: it proves the code works, not that gestures work on a head.
- Real takes recorded with `Nod --record` live in `~/Library/Application Support/Nod/recordings/` and never leave the Mac; copy one here only on purpose.
